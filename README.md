# Lotería

App web estática (HTML/CSS/JS puro, sin backend) para sortear números sin repetición dentro de un rango, con historial y sonido de sorteo. Pensada para jugar a la lotería/bingo desde el celular.

## Uso local

Abrí `index.html` directamente en el navegador, o serví la carpeta con cualquier servidor estático:

```
npx serve .
```

## Deploy en GitHub Pages

1. Subí este proyecto a un repositorio de GitHub.
2. En el repo, andá a **Settings → Pages**.
3. En "Build and deployment", elegí **Deploy from a branch**, rama `main` (o `master`) y carpeta `/ (root)`.
4. Guardá. GitHub te va a dar una URL tipo `https://<usuario>.github.io/<repo>/`.
